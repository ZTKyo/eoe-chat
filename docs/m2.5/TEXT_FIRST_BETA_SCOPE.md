# EOE Chat Text-First Fixed-Level Beta Scope

## Product position

EOE Chat is first an ordinary text-chat assistant. It should remain useful for normal conversation, knowledge questions, opinions, advice, technical explanations, planning, comparison, emotional support, and multi-turn work even when no English appears.

English learning is delivered only as a natural Overlay inside a complete answer. It is not a course home page, task system, score, check-in, vocabulary card stream, or mandatory English quota.

## Included in Beta

- Text conversation and multi-turn context;
- knowledge, analysis, advice, explanation, planning, and comparison;
- fixed-level English Overlay and legitimate noFit;
- user Phrase reuse;
- explicit Vocabulary Assistance with topic continuation;
- Chinese-only scope and explicit resume;
- local IndexedDB history, PWA, Desktop, and Mobile.

## Excluded from Beta

New image upload, image analysis, and image English Overlay are not release gates for this Beta. Vision implementation and historical image data remain in the repository and database, but new image input is disabled by default.

Adaptive Progression is not included. The fixed long-term level does not promote or demote automatically.

## Evidence boundary

The Beta is intended to collect real human feedback about:

- whether displayed English is natural;
- whether users understand it from context;
- whether noFit is appropriately conservative;
- whether assistance is useful without turning the chat into Teacher Mode;
- whether ordinary task completion remains strong.

This Beta does not claim Mastery, automatic learning effectiveness, or validated long-term acquisition outcomes. Structural and automated tests are engineering evidence, not independent human naturalness approval.
