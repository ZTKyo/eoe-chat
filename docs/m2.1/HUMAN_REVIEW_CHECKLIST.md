# Human Review Checklist

## 重要说明

以下是 MockProvider 产生的 20 条实际输出样本。机器只完成结构风险预检；“完整回答用户”“英文是否自然”“删除英文是否破坏原意”“是否值得保留”“是否应 noFit”等主观结论必须由独立人工审核。当前统一状态为 PENDING_INDEPENDENT_HUMAN_REVIEW，不得由同一生成模型自行宣布全部自然。

每条人工审核项：完整回答用户 / 英文自然 / 删除英文是否破坏原意 / 是否只是中文翻译 / 是否像标签 / Segment 边界 / 标点 / Teacher Mode / 是否值得保留 / 是否应 noFit。

## 当前结论边界

自动化可确认没有默认冒号标签、直接翻译、超预算、非法 Phrase ID 或边界结构错误。自然度、回答充分性和语气仍需真实 Provider 输出与独立人工审核确认。
