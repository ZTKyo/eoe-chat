# Vocabulary Assistance Contract v1

Vocabulary Assistance is user-triggered and contextual. Valid triggers are an English Chunk click/long press or an explicit question about its meaning, pronunciation, or identity.

The Engine resolves a source message, English segment, Phrase ID, full source sentence, previous user message, and current topic. Output briefly includes the complete source sentence, pronunciation, contextual meaning, and only when useful one short related example, then resumes the original topic.

It must not become a lesson, explain every word, add exercises, require repetition, show a flash card, or abandon the original topic. If more than one Phrase is plausible, ask which one. Deny the existence of a prior Phrase only after the actual message history has been checked.
