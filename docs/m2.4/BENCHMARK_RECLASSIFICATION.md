# Benchmark Reclassification

`benchmark:naturalness` is deprecated. `benchmark:structure` is the canonical MockProvider command and its report is named **Structural Realization Benchmark**.

It validates Schema, Parser, Template, Mapper, Segment construction, noFit, retry, Validator, Exposure, Assistance, and regression behaviour. Mock text is not evidence of product reply quality.

Mock results must not contribute to Human Naturalness Pass, Adaptive Progression, Comprehension Evidence, or Phrase Activation Evidence. The deprecated alias prints `DEPRECATED_ALIAS — use benchmark:structure` before running the structural suite. Synthetic confidence or `natural=true` must not be presented as human/model evaluation.
