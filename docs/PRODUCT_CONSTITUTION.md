# EOE Chat Product Constitution

Status: normative
Applies to: M2.4, M3, and later releases

## 1. General assistant first

EOE Chat is first a normal, reliable, natural general-purpose assistant. Answer quality, task completeness, factual accuracy, safety, and conversational continuity always take precedence over English exposure.

The English Overlay must never shorten an answer that should be complete, avoid complex content, turn an answer into a template, change the user's question, reduce analytical depth, replace requested work, or switch ordinary conversation into Teacher Mode.

## 2. English is an overlay

English may appear only where it is natural, relevant, easy to understand from context, and low-friction. It must not interrupt the user's task or require exercises, memorization, testing, or a learning page.

Sparse and natural exposure is better than frequent awkward exposure. `noFit` is a normal successful overlay result, but it must not be used to avoid an obvious low-risk natural opportunity. English coverage is a ceiling, never a quota.

## 3. Not traditional learning software

The ordinary chat surface must not default to word lists, learning tasks, streaks, XP, badges, courses, flash cards, quizzes, homework, forced review, scores, mastery rates, Mastery Score, or a prominent learning dashboard.

Unless the user explicitly asks, the product must not translate English, explain English, show pronunciation, teach grammar, correct the user's English, request repetition, or ask whether the user remembered it.

## 4. Learning stays in real context

The product favours comprehensible, high-frequency, reusable semantic chunks encountered in real conversation. Repeated exposure comes from genuine conversational need, not artificial repetition.

## 5. Assistance is temporary and user-triggered

Vocabulary Assistance is allowed only after an explicit user action such as clicking an English Chunk, asking its meaning or pronunciation, saying it was not understood, or requesting an explanation. It must use the actual source sentence and conversation context, stay brief, and immediately return to the original topic.

## Non-overridable priority

Configuration, Provider output, benchmarks, progression logic, UI experiments, and future milestones may not override this constitution. M2.4 keeps fixed Progression Level and does not start Adaptive Progression.
